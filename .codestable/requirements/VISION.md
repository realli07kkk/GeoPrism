## current（系统正在满足的能力）

| 能力 | Pitch |
|---|---|
| [多 Provider DNS 查询](./multi-provider-dns-query.md) | 一条命令同时问多个 DNS 服务商，结果并排摆出来，还能顺手测谁连得上、域名归谁管 |
| [离线 IP / CIDR 查询](./offline-ip-lookup.md) | 把整张 IP 地理库塞进本地，断网也能查 IP 归属，还能按网段批量看一片 IP 的归属 |
