# 多格式输出

## 用户故事

- 作为一个在终端里直接查结果的开发，我希望输出是彩色表格、字段对齐、一眼能扫到关键信息，而不是挤在一起的纯文本。
- 作为一个把 GeoPrism 嵌到自动化脚本里的 SRE，我希望加个 `-j` 就能拿到结构化 JSON，不需要自己写解析器从文本输出里抠字段。
- 作为一个把输出重定向到文件的用户，我希望工具自动识别不是终端就不渲染颜色，文件里不会出现 ANSI 转义码。

## 为什么需要

CLI 工具的两类用户——人和脚本——对输出的需求完全不同。人需要视觉层次：颜色、对齐、一眼能抓到关键字段；脚本需要机器可解析的 JSON。没有这个能力的话，要么人类用户忍受难读的纯文本，要么脚本用户写脆弱的文本解析逻辑。

## 怎么解决

工具检测是否在终端（TTY）里运行：TTY 下启用彩色增强表格渲染；非 TTY（管道、重定向、脚本）保持纯文本表格协议。所有查询命令支持 `-j` 参数输出结构化 JSON，错误信息也以 JSON 格式输出到 stderr。

## 边界

- 不提供 CSV、XML、YAML 等其他输出格式。
- JSON 模式下错误信息输出到 stderr 而非 stdout，调用方需分别读取。
- TTY 检测基于标准输入输出的文件描述符，不被环境变量覆盖。
