# IP 地理位置查询

## 用户故事

- 作为一个在飞机上想查某个 IP 归属的开发，我希望离线也能查到结果，而不是等落地有网了再说。
- 作为一个需要批量确认一组 IP 是否属于同一网段的人，我希望直接敲一个 CIDR 就看到所有相交网段，而不是自己写脚本拆 IP 再一个个查。
- 作为一个偶尔才查 IP 的人，我没有离线库也不想先花时间构建，但我有 ipinfo token，希望能直接用在线查询拿到结果。

## 为什么需要

查 IP 归属是安全分析、运维排障、反欺诈里的高频操作。在线查询依赖网络、有频率限制、响应慢；离线方案通常需要自己搭服务。这个能力让你把离线速度、在线兜底和自己控制数据源优先级三者统一在一个命令里。

## 怎么解决

用户敲一个 IP 或 CIDR 网段，工具先查本地离线库——无网络、低延迟。离线库没命中时，如果用户配了 ipinfo token，自动回退到在线查询。在线查到的结果会异步写回本地库，下次同样的 IP 就不用再联网了。用户可以配置优先查哪个数据源。

## 边界

- 不提供 IP 定位之外的维度（不查恶意情报、不查 WHOIS）。
- 离线库需要用户自己构建——工具提供构建命令，但不自带 IP 数据。
- 在线回退依赖 ipinfo 服务可用性和用户 token 配额。
- CIDR 查询只在本地库中匹配相交网段，不回退到在线。
- 不实时更新离线库——库更新是另一个独立流程。
