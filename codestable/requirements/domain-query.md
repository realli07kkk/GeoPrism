# 域名 DNS 查询

## 用户故事

- 作为一个刚接手运维的人，我想敲一个域名就看到所有 DNS 记录，而不是先翻手册学 dig 参数再一个个试。
- 作为一个怀疑某个 DNS 服务器返回结果有问题的开发，我想并行查多个 Provider 的结果并排对比，而不是手动开三个终端窗口。
- 作为一个想知道域名托管在哪个 NS 的人，我希望查域名的时候顺带看到 NS 服务器信息，而不是再跑一次独立查询。

## 为什么需要

查一个域名的 DNS 解析结果是运维和开发的日常动作，但原生命令行工具（dig、nslookup）学习成本不低——记参数、区分记录类型、理解输出格式，每一步都在消耗注意力。要对比多个 DNS 服务器的结果时更麻烦，得手动串行执行、肉眼对齐。这个能力把"查域名"这件事简化到一行命令，同时给你一个并排对比视图。

## 怎么解决

用户敲域名，工具同时向所有已配置的 DNS Provider 发起查询，把各 Provider 返回的记录并排展示。支持 DoH、DoT、传统 DNS 三种协议。域名查完后自动追加该域名的 NS 服务器信息。

## 边界

- 不修改 DNS 记录——这是查询工具，不是管理工具。
- 不替代权威 DNS 服务器——它只是把多个上游的结果汇总展示。
- 需要网络连接，不提供离线 DNS 数据。
- Provider 需要用户先配置好，工具不自带 DNS 服务器列表。
